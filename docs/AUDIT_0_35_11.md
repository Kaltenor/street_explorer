# Polygon, gap and loading audit — 0.35.11

Version 0.35.10 / build 240 becomes 0.35.11 / build 241. Work started from a clean checkout.

## Changes

- Polygon contour bounds receive a per-build spatial index, avoiding all-hole/all-island comparisons. Individual city boundary rings receive bounds and an early outer-ring rejection. No persistent spatial-index cache is retained.
- Four map-layer caches each retain only their last cell snapshot, fill limit and result. Equivalent reloads reuse polygon references; changed inputs rebuild, failed builds do not publish, and hidden layers retain the prior result. Memory remains proportional to the latest visible dataset, not an unbounded history.
- The coalescing hook clears its canceled timer ref so an effect replay can schedule again.
- Gap routing constructs topology lazily, releases temporary snaps after both acceptance and rejection, and reconstructs paths by reverse/push rather than repeated unshift.
- Interior crossing snaps and consecutive crossings connect directly along their validated street edges instead of forcing detours through endpoints. Algorithm 5 applies to new/explicitly reprocessed snapshots; historical snapshots stay frozen.
- Language changes no longer reload core map data. Album changes reuse the saved-map snapshot (eight reads avoided) and do not republish identical cell arrays; explicit mutation refreshes still reread. Hidden paths skip refreshes and obsolete async scope results cannot replace the latest selection.

## Validation

Tests exercise 1,500 rings, nested islands, independent area conservation and exact baseline equality on 60 deterministic irregular grids. Gap tests cover internal turns, two successive intersections, grade-separated geometric crossings, graph cleanup on success/rejection and standalone/shared-context equivalence. Loading tests execute production callbacks to verify concurrency, snapshot eviction after failures, null selection and stale-result suppression.

Local offline iOS/Hermes export passed (5.89 MB bundle). TypeScript, including unused-local/parameter checks, passed. The full npm test aggregate passed, including geometry, resilience, UI/loading and documentation checks. Physical startup/Stop timings, native rendering, location delivery and live street-server behavior require the [device protocol](TESTING.md#polygons-gaps-and-loading--03511).

## Remaining limits

Historical finding resolved in 0.35.12: the coordinate-only graph could connect a road and an overpass at coincident vertices. Grade-scoped vertex keys now prevent that connection, and explicit shared OSM node IDs preserve legitimate bridge/tunnel entrances. Parser, splitter and inference regression tests cover both cases. Legacy cached streets without IDs conservatively reject cross-grade transitions until refreshed. Existing snapshots require explicit reprocessing. GPS snapping ambiguity and incomplete OSM data remain possible.

Full polygon generation is still synchronous when actual cells change. Large native polygon counts, individual backup records and initial database I/O can still pause a real device. Date-line enclosure connectivity remains unsupported. Existing frozen gaps change only after explicit reprocessing. No gain in real phone launch time is claimed without traces from that device.
