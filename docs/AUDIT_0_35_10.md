# Player and stability follow-up — 0.35.10

Version 0.35.9 / build 239 becomes 0.35.10 / build 240. This delivery includes the preceding [maintenance audit](AUDIT_0_35_9.md), which was still uncommitted when follow-up work began.

## Player assets and display

The built-in image generation tool recreated the existing costume with more natural adult proportions and directional gait poses. [Exact prompt](../assets/player/GENERATION_PROMPT.md); source and twenty runtime frames live in assets/player. The extraction script derives framing from visible alpha (ignoring near-transparent gutter noise for bounds), retains alpha, applies one scale across all poses and aligns resized boot silhouettes at y=60. This avoids pose-dependent resizing and foot jitter. No extra animation library or dependency was added.

Confirmed fixes in ExplorationMap.tsx:
- Screen-facing direction subtracts native camera heading after region movement completes; asynchronous camera responses are guarded against remounts.
- Walking intervals pause in background and with Reduce Motion; freshness is recalculated on foreground return.
- Google marker snapshots freeze only after all frames decode, layout completes and a final redraw/transition delay. Moving sprites keep tracking; Apple foreground behavior is preserved.
- Constant walking speed no longer triggers stationary speech after 45 seconds. The timer samples current fresh motion; stale GPS does not prove immobility.
- Backgrounding cancels speech timers and clears active/pending messages, preventing replay of obsolete text.

## Persistence follow-up

Backup block reading compares the full verified manifest before yielding blocks, including when a replacement archive reuses its backup ID. Installed country packs survive temporary filesystem read errors. Downloaded albums enter memory only after successful installation; a failure removing obsolete files no longer changes an installed pack into a reported failure. Behavioral tests inject each condition.

## Validation and limits

npm test and the additional TypeScript unused-local/parameter checks pass. Player tests execute the production animation/timer logic and decode all twenty RGBA frames to check transparent margins, consistent boot baseline and matching idle/stale silhouettes. Offline local iOS/Hermes export passed (5.88 MB bundle); no remote build was launched. Tests do not establish physical MapKit/Google rendering or GPS behavior; [the device protocol](TESTING.md#player-presentation--03510) remains required.

No phone FPS improvement is claimed. Snapshot freezing removes repeated idle Google rasterization structurally; device timings remain unmeasured. The earlier geometry benchmark remains documented separately. The generated three-pose gait is a stylized approximation, not motion capture. No reachable feature or user data was removed in this follow-up.
