# Bundled Sound Assets

`atlas-page.wav` is the CC0 **Turned Page** recording by DavidGreck, downloaded from BigSoundBank:

- Source: https://bigsoundbank.com/turned-page-s0164.html
- License: Creative Commons Zero 1.0 / public domain equivalent

`atlas-reward-jingle.wav` is the CC0 **Win sound effect** by Listener, downloaded from OpenGameArt:

- Source: https://opengameart.org/content/win-sound-effect
- License: Creative Commons Zero 1.0

`medal-chime.wav` is an original two-second stereo orchestral reward cue generated by `scripts/generate-medal-chime.js`. It combines a rising brass call, a sustained string-and-brass resolution, timpani impacts, bell shimmer, and restrained synthetic hall reflections. It contains no third-party samples or melodies.

- Source: Street Explorer procedural synthesis
- License: Creative Commons Zero 1.0 / public-domain dedication

The assets are bundled locally so Atlas navigation, medal unlocks, and reward feedback work offline. Attribution is not required by CC0, but the sources and generation method are retained here for provenance.
